# UI/UX Pro Max Standartları
1. Hick Yasası: Ana ekranda daima 1 birincil odak (CTA) butonu bulunmalıdır.
2. Aşamalı Gösterme: Karmaşık mekanikler ve güç açıklamaları oyun içi anlarda gösterilmelidir.
3. Metin Yerine İkon: Açıklama paragraflarını kaldır, sembol ve rozetler kullan.
